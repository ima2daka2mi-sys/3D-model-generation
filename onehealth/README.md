# ワンヘルス・クエスト（仮称） — 3D 体験空間

提案書「ワンヘルスを踏まえた動物愛護理解促進」（4〜5章）をもとにした、ブラウザで動く 3D 体験空間のプロトタイプです。

公開 URL: https://ima2daka2mi-sys.github.io/3D-model-generation/onehealth/

## 構成（ハブ＆スポーク）

| 場所 | 内容 | トラブル |
| --- | --- | --- |
| エントランス広場（ハブ） | キービジュアル、各エリアへのゲート（進捗表示つき） | — |
| A. ワンヘルスの理念 | 人間環境エリア（町・農場）↔ 自然環境エリア（森・川）を1つのエリアで連続 | 森林伐採・ごみ投棄／野生動物への餌付け／動物の薬剤耐性／抗菌薬の自己判断中断／マイクロプラスチック |
| B. 人獣共通感染症対策 | 猫カフェエリア、自宅エリア | 傷口をなめる猫／触れ合い後の手洗い／体調の悪い犬のフン／Tips：犬の足跡／過度な接触 |
| C. ペットの災害対策 | 自宅エリア、避難所（体育館）エリア | 同行避難のフード／在宅避難の備え／防災バッグ準備ミニゲーム／身元表示のない犬（距離で鳴き声）／避難所での配慮 |

## 遊び方

1. トラブルマーク（赤い「!」）に近づいて「調べる」
2. まちがった行動が示されるので、なぜダメなのかを A/B で選ぶ
3. 「このままだと…」の被害シナリオ（空間内の演出つき）→「正しい対処」→ マークが消える
4. エリア内のマークをすべて解決するとクリア。全問正解でゴールド、それ以外はシルバースタンプ
5. 3エリアともゴールドで称号「ワンヘルスマスター」。正解率に応じた称号（マルチエンディング）

- アバター：肌・髪型・髪色・上下の服と色を組み合わせ（性別を固定しないパーツ構成）
- 視点：三人称／一人称を切り替え
- 操作：タップ（クリック）した場所へ移動、スティック／WASD、ドラッグで見回し、ピンチ／ホイールでズーム
- 進捗（ベストスタンプ）とアバターはブラウザに保存

## ファイル

```
onehealth/index.html     UI（HUD・ダイアログ）
onehealth/src/content.js シナリオ・クイズ文面（提案書 5.2〜5.5 から作成）
onehealth/src/world.js   ハブ・3エリアの空間生成、当たり判定
onehealth/src/models.js  ローポリの動物・アバター・建物・家具
onehealth/src/main.js    操作、カメラ、クイズ進行、演出、効果音、スタンプ
```

three.js はリポジトリ直下の `vendor/` を共有しています。
